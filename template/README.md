# Design template

This folder is the **visual law**. Copy it. Do not restyle it. Point it at a new `*.sheaf.json`.

| file | role |
| --- | --- |
| `tokens.css` | Sanzo Wada tokens. Olive-buff paper, ube, emerald, gold. |
| `volume.js` | Curvilinear ρ, last-folder pillars, up/down fans, six design views. |
| `index.html` | Chrome. Loads catalog + any rolled sheaf. |

Views (mode remaps which ρ family is drawn):

1. **pillars** — mesh only  
2. **rho** — restriction maps  
3. **strata** — kind becomes height  
4. **harmonic** — known B stays  
5. **trunk** — only `ok` ρ is thick  
6. **subspaces** — type discs, artifacts drop via lives-at  

Pause is default. Cap = ancillary (up). Base = downstream (down). Gold is earned (`onTrunk`).

When rolling a new sheaf, keep these files. Swap JSON only.
