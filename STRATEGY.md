# Cell-Sheaf Observatory Strategy

See [docs/INTEGRATION.md](docs/INTEGRATION.md) for the two-repo map. This document states product direction for the unified kernel + publish surfaces.

## Purpose

Teams running multi-agent or multi-repo work lack a **single readable volume** where restriction maps (ρ), glue status, and swarm motion share one law. The crux: dashboards show activity, but not **which one map repair opens the trunk** — so operators commit on broken coboundaries.

## Positioning

We commit to **JSON-as-sheaf, color-as-glue**: no fork of the Wada template, no restyle of `tokens.css`. A neighbor can copy HTML chrome; only this stack ships SheafGraph validation, adversarial EVAL seats, and a federated running loop with meta-learned repair weights.

## Users

**Primary:** Operator-architect — they're hiring Cell-Sheaf Observatory to see where agent swarms are blocked on ρ, run federated ticks safely paused-by-default, and export a rolled contract without breaking ROLL law.

**Secondary:** Design-template adopter — copies `template/` from cell-sheaf Pages to mint new sheaves; needs kernel docs and validate CLI, not React.

## Boundaries

- Not a general DAG or workflow SaaS — stalks stay last-folder pillars, edges stay ρ with four glue statuses.
- Not a fork of OAH — inspiration only (per README).
- Not a second visual theme — tokens are fixed; insight changes are verdict copy and curve weight, not palette.
- Not replacing GitHub Issues/Linear — the sheaf **indexes** work; it does not become the issue tracker.

_Resist a change when:_ it adds a fifth glue status or treats links as undirected edges "for convenience."

## Key metrics

- **Trunk closure rate** — share of catalog specimens where every pillar has a legal incident ρ; measured in CI (`sheaf:validate` + federation report).
- **Verdict actionability** — operator can name top repair in one glance; measured by EVAL seat pass rate in federation runs.
- **Template drift** — diff count between cell-sheaf and cell-sheaf-swarm `template/` on release; measured by sync job (target: zero on tag).
- **JEV progress** — federated JEV sum toward 128 per run; logged in `.meta-learning/last-report.json`.

## Tracks

### Contract kernel

Schema, ROLL, validate script, catalog specimens — the publishable npm `files` list.

_Why it serves the approach:_ Without validate, glue is decoration; gold is not earned lawfully.

### Readable volume (HTML + Observatory)

Pages template plus Vite observatory for six swarm modes and insight repairs.

_Why it serves the approach:_ EVAL P0 seats fail when the header shows counts but not **what to do**; insight + verdict fix that.

### Federated running loop

Multi-cell `pulse`, four-seat eval, meta-learning weights on block events.

_Why it serves the approach:_ Single-thread UI demo does not stress orchestrator ↔ eval ↔ lattice-ops; federation matches the broken `r-op` story in the specimen.

## Brand

**One-liner:** Restriction color is glue. Gold is earned.

**Key message:** Copy the template, swap the sheaf, run the loop — do not restyle the paper.
